AtomS3R-CAM / GC0308

Visual Pose Tracker

2個の ArUco DICT_4X4_50 マーカーを、縦方向の既知レーンから捕捉して 小さなROIで追跡する実験ファームウェアです。

01 · Firmware

ブラウザから書き込む

AtomS3R-CAMをUSBで接続し、下のボタンから書き込みます。 Chrome / Edge のWeb Serialを使用します。

このブラウザはWeb Serialに対応していません。ChromeまたはEdgeを使用してください。

HTTPSページから開いてください。

書き込みモード: Resetを約2秒長押し → 内部の緑LED点灯 → 離す。
