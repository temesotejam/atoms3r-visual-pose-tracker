AtomS3R-CAM / GC0308

Visual Pose Tracker

2個の ArUco DICT_4X4_50 マーカーを上下の水平帯域から捕捉し、 捕捉後は2段の局所追跡で高速に追従する実験ファームウェアです。

01 · Firmware

ブラウザから書き込む

AtomS3R-CAMをUSBで接続し、下のボタンから書き込みます。 Chrome / Edge のWeb Serialを使用します。

公開ファーム情報を確認中…

このブラウザはWeb Serialに対応していません。ChromeまたはEdgeを使用してください。

HTTPSページから開いてください。

書き込みモード: Resetを約2秒長押し → 内部の緑LED点灯 → 離す。 書き込み後は通常起動してから下のシリアルへ接続してください。
